# Projeto Calculadora - Kaick - RA 240328

Este projeto foi desenvolvido em Java para a atividade de **Testes Funcionais, Refatoração e Documentação de Software**.

A calculadora realiza operações matemáticas básicas:

- Soma
- Subtração
- Multiplicação
- Divisão

Também possui tratamento para divisão por zero e operação inválida.
